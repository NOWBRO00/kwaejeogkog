📋 준비 단계 (처음 한 번만)

1. 필요한 라이브러리 설치
   cd "C:\Users\wogud\Desktop\comfortCock_cam\kwaejeogkog"
   pip install opencv-python numpy firebase-admin sounddevice

   (마이크를 사용하지 않으면 sounddevice는 선택사항)

==========================================
🚀 실행 단계 (매번 실행)
==========================================

【터미널 1】 웹 서버 실행

1. 터미널 열기 (PowerShell 또는 CMD)
2. 프로젝트 폴더로 이동:
   cd "C:\Users\wogud\Desktop\comfortCock_cam\kwaejeogkog"

3. 웹 서버 실행:
   python -m http.server 8000

4. 성공 메시지 확인:
   "Serving HTTP on :: port 8000 ..."

5. 브라우저에서 접속:
   http://localhost:8000

   (웹 서버는 계속 실행 상태로 유지)


【터미널 2】 Python 프로그램 실행

1. 새 터미널 창 열기 (PowerShell 또는 CMD)
2. 프로젝트 폴더로 이동:
   cd "C:\Users\wogud\Desktop\comfortCock_cam\kwaejeogkog"

3. Python 프로그램 실행:
   python main.py

4. 웹캠 창이 열리면:
   - 마우스로 좌석 영역을 드래그하여 그리기
   - 여러 좌석 추가 가능

5. 키보드 단축키:
   - 's' 키: 좌석 설정 저장 (seats_config.json)
   - 'c' 키: 모든 좌석 초기화
   - 'q' 키: 프로그램 종료


【브라우저】 대시보드 확인

1. http://localhost:8000 접속
2. 실시간으로 확인 가능:
   - 좌석별 상태 (점유/공석/유령)
   - 온도/습도/소음 데이터
   - 쾌적 지수
   - 통합 소음 레벨
   - 환경 정보 (여름/겨울)

==========================================
⚠️ 주의사항
==========================================

1. 웹 서버와 Python 프로그램은 별도 터미널에서 실행
2. 웹 서버는 종료하지 말고 계속 실행 상태 유지
3. Python 프로그램 종료: 'q' 키 또는 Ctrl+C
4. 웹 서버 종료: 터미널에서 Ctrl+C
