==========================================
쾌적콕 카메라 시스템 실행 방법
==========================================

1. 터미널 열기
   - PowerShell 또는 CMD 실행

2. 프로젝트 폴더로 이동
   cd "C:\Users\wogud\Desktop\comfortCock_cam\kwaejeogkog"

3. 필요한 라이브러리 설치 (처음 한 번만)
   pip install opencv-python numpy firebase-admin

4. 웹 서버 실행 (새 터미널 창에서)
   
   방법 1: 다른 포트 사용 (권장)
   python -m http.server 8000
   브라우저에서 접속: http://localhost:8000
   
   방법 2: 8080 포트 사용 (이미 사용 중이면 오류 발생)
   python -m http.server 8080
   브라우저에서 접속: http://localhost:8080
   
   만약 포트 오류가 발생하면:
   - 다른 포트 번호 사용 (8000, 3000, 5000 등)
   - 또는 기존 프로세스 종료 후 재시도

5. Python 프로그램 실행 (또 다른 터미널 창에서)
   python main.py

6. 사용 방법
   - 웹캠 창이 열리면 마우스로 좌석 영역을 그립니다
   - 's' 키: 좌석 설정 저장
   - 'c' 키: 좌석 설정 초기화
   - 'q' 키: 프로그램 종료

7. 화면 표시
   - 각 좌석에 온도(°C)와 소음(dB) 표시
   - 좌석 상태: 빨강(점유), 초록(공석), 주황(유령)
